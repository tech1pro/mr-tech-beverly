# Build with Ricky

The planner is a standalone web component in `pc-builder.js`. It uses the website's color variables when present and includes its own fallback styles.

Embed it on another page using:

```html
<mr-tech-builder></mr-tech-builder>
<script src="pc-builder.js" defer></script>
```

It generates a preference brief and component checklist, not a live product catalog. No prices, compatibility guarantees, affiliate commissions, reservations, or stock checks are implied. It sends nothing automatically. Customers send the prepared message through their own messaging app.

User inputs stay in the page until copied or sent by the visitor. The component does not save submissions or use a backend.
